# Planner

# ![Planner](https://github.com/user-attachments/assets/5ce2ff3b-c563-457a-af63-23ef12524402)


## Descrição

**Planner** é um aplicativo frontend projetado para ajudar no planejamento de viagens, sendo desenvolvido no NLW Journey React da Rocketseat. Com o Planner, você pode organizar seus destinos, datas, gerenciar convidados e enviar convites por e-mail de maneira simples e eficiente.

## Funcionalidades

- **Organização de Viagens:** Planeje e organize seus destinos e datas de viagem.
- **Gerenciamento de Convidados:** Adicione convidados e envie convites diretamente por e-mail.
- **Visualização Clara:** Interface limpa e intuitiva, facilitando a navegação e o planejamento.

## Tecnologias Utilizadas

- **React:** Biblioteca JavaScript para construir interfaces de usuário.
- **TypeScript:** Superconjunto do JavaScript que adiciona tipagem estática ao código.
- **Tailwind CSS:** Framework CSS utilitário para estilização rápida e eficiente.
- **React Router:** Biblioteca para navegação e gerenciamento de rotas em aplicações React.
- **Axios:** Cliente HTTP para realizar requisições à API.

## Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/planner.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd planner
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Execute o projeto:
   ```bash
   npm start
   ```
